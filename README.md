# clipmeta

Clip and reshape meta text streams with deterministic transforms.

**Site:** https://theworker02.github.io/clipmeta/

## Install / run

```bash
git clone https://github.com/theworker02/clipmeta.git
cd clipmeta
node src/cli.js
node --test
```
